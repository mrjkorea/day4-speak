# Day 4 Speak (MRJ)

Kid-friendly Day 4 speaking practice for **Basic A / B / C**.

1. See Korean → tap to hear English  
2. Speak English into the mic  
3. Pass at **≥ 80%** match  

Live on GitHub Pages. Records stay in the browser (`localStorage`) and can be downloaded as JSON.
